# 月別集計（サンプルデータ）

前提: サンプルデータあり

サンプルデータは当月の1日〜18日に置かれた収入1件・支出10件、月予算250,000円、カテゴリ別予算5件。

## 手順

1. 月別集計タブを開く（起動直後の画面）
   - 期待: 収入合計が「320,000円」、支出合計が「123,270円」、収支差額が「196,730円」
   - 期待: 今月の予算が「250,000円」、残額が「126,730円」、予算判定が「予算内」
2. 「カテゴリ別支出」を見る
   - 期待: 支出の多い順に 家賃 85,000円、食費 12,570円、光熱費 12,500円、娯楽 8,700円、交通費 4,500円 が並んでいる
   - 期待: 家賃の構成比が「69.0%」、食費が「10.2%」
3. 画面を下にスクロールして「この月の収支」を見る
   - 期待: 新しい日付順に並び、先頭が当月18日の「カフェ・パン」2,450円、末尾が当月1日の「給与」320,000円
4. さらにスクロールして「カテゴリ別予算比較」を見る
   - 期待: 家賃「支出 85,000円 / 予算 85,000円」、食費「支出 12,570円 / 予算 50,000円」、交通費「支出 4,500円 / 予算 15,000円」、光熱費「支出 12,500円 / 予算 20,000円」、娯楽「支出 8,700円 / 予算 20,000円」
   - 期待: 給料は「支出 0円 / 予算 0円」
   - 期待: 全カテゴリが「予算内」（家賃は支出と予算が同額なので超過にならない）
