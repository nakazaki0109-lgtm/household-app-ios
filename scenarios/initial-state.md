# 空の初期状態

前提: 空の初期状態

初回起動直後の状態を確認する。

## 手順

1. 月別集計タブを開く（起動直後の画面）
   - 期待: ナビゲーションバーのタイトルが「月別集計」で、当月（例: 2026年9月）が表示されている
   - 期待: 収入合計・支出合計・収支差額・今月の予算・残額がすべて「0円」で、予算判定が「予算内」
   - 期待: 「この月のカテゴリ別支出データはありません。」と「この月のデータはありません。」が表示されている
2. 画面を下にスクロールして「カテゴリ別予算比較」を見る
   - 期待: 食費・交通費・家賃・光熱費・娯楽・給料の6カテゴリだけが並び、どれも「支出 0円 / 予算 0円」「予算内」
3. 画面下のタブ「収支一覧」をタップする
   - 期待: 「まだ収支データがありません。」が表示されている
4. `transactionList.addButton` をタップし、`transactionCreate.categoryPicker` をタップする
   - 期待: 選択肢が「選択してください」と上の6カテゴリだけである
5. 選択肢の「選択してください」をタップして選び直し、`transactionCreate.cancelButton` をタップする
   - 期待: 収支登録画面が閉じ、収支一覧に戻る
