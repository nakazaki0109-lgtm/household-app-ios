# 収支一覧（サンプルデータ）

前提: サンプルデータあり

## 手順

1. 画面下のタブ「収支一覧」をタップする
   - 期待: ナビゲーションバーのタイトルが「収支一覧」
   - 期待: 先頭の行が、当月18日・支出・食費・「カフェ・パン」・2,450円
   - 期待: その下に 16日「友人と食事」6,800円、14日「ガス代」4,100円、12日「まとめ買い」5,640円 が新しい日付順に続く
2. 画面を下にスクロールする
   - 期待: 1日の「給与」（収入・給料・320,000円）が最後に表示される
   - 期待: 行は合計11件（収入1件・支出10件）
3. `transactionList.addButton` をタップする
   - 期待: 「収支登録」画面が下から開く
4. `transactionCreate.cancelButton` をタップする
   - 期待: 収支登録画面が閉じ、収支一覧に戻る。件数は変わらない
